# AI Agent - GitHub & Jira Integration

AI chat app for GitHub and Jira operations through natural language.

## Features
- GitHub: Repos, issues, PRs, code search
- Jira: Projects, issues, workflows
- 50+ AI tools

## Setup

```bash
git clone git@github.com:joshsoftware/Hackathon-Aug-25-Team1.git
cd Hackathon-Aug-25-Team1/app
npm install
```

Create `.env.local`:
```env
ANTHROPIC_API_KEY=your_key
OPENAI_API_KEY=your_key
```

Run:
```bash
npm run dev
```

Open: http://localhost:3000

## Usage
- "Show facebook/react repo info"
- "Search ML repos with 1000+ stars"
- "Create bug in project TEST"
